# 🐾 桌面宠物程序说明与优化

## 📌 项目简介

这是一个基于 **PySide6** 开发的桌面宠物程序（Table Pet）。程序在桌面显示一个动态角色，支持动画切换、鼠标拖拽移动、系统托盘交互、气泡对话、窗口透明/穿透/置顶等特性。[恩师](https://www.douyin.com/user/MS4wLjABAAAA0gqcA78H7aEk8PJJ8BBeVIMSxYknpNcqwuCjfL1hPcZyuGlqJsB_cwT7Pw11eLHw?from_tab_name=main&relation=0&vid=7625138275870674195)

## ✅ 现有功能清单

### 1. 基础窗口
- 无边框、置顶显示
- 背景透明
- 固定大小 (280×120)
- 窗口启动时位于屏幕右下角

### 2. 动画系统
- 支持多种动作动画：吃、左移、擦汗、睡觉、生气、流泪
- 动画自动循环播放
- 可通过事件触发切换动画

### 3. 鼠标交互
- **左键拖拽**：窗口可跟随鼠标移动
- **右键菜单**：弹出窗口控制菜单（左移动、透明度、置顶、退出）

### 4. 系统托盘
- 托盘图标常驻系统通知区
- 托盘右键菜单功能：
  - 调整透明度（预设值 + 自定义）
  - 切换窗口置顶
  - 切换窗口穿透（鼠标不可点击）
  - 退出程序

### 5. 气泡对话
- 气泡背景图片 + 文字显示
- 根据当前动画状态随机显示对应风格的话术
- 自动定时显示 / 隐藏

### 6. 自动行为
- 随机切换表情（定时 30–60 秒）
- 定时显示对话气泡（15–35 秒）
- 非默认动画结束后自动恢复默认动画（吃）
- 支持向左移动动画并自动折返

### 7. 窗口高级功能（Windows）
- 调用 Win32 API 实现窗口穿透（鼠标事件直接穿透到下层窗口）
- 支持分层窗口样式

## 🧠 代码结构

| 模块 | 说明 |
|------|------|
| `MainWindow` | 主窗口类，包含所有功能 |
| `__init__` | 初始化窗口属性、托盘、动画、计时器、布局 |
| `find_project_root` | 自动定位项目资源根目录（图片文件夹） |
| 动画切换方法 | `ImageEat`, `ImageLeft`, `ImageCahan` 等 |
| 托盘初始化 | `initTray` + 透明度 / 穿透 / 置顶逻辑 |
| 鼠标事件 | `mousePressEvent`, `moveEvent`, `releaseEvent` |
| 窗口穿透 | `set_window_hit_test_visible`（Qt + Win32） |
| 随机行为 | `random_look`, `play_random_look`, `random_text` |
| 定时器系统 | `QTimer` 控制动画恢复、移动、气泡、随机表情 |
